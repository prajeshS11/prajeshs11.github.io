# Prajesh Sivakumar — Cybersecurity Portfolio

A responsive, static personal portfolio built with HTML, CSS, and vanilla JavaScript. The content focuses on cybersecurity, networking, programming, and responsible hands-on learning. It also includes education details for B.Tech in Computer Science and Engineering at LNMIIT and the BS in Management and Data Science at IIT Madras (Foundation Level).

## Themes
A **THEME** button in the header lets visitors switch between Dark (default), Light, Matrix, Ocean, and Sunset. The choice is saved in the browser (`localStorage`). To add a theme, add a `[data-theme="name"]` block in `styles.css` (copy an existing one), add a matching `<li>` in the theme menu in `index.html`, and add the name to the list in the small `<head>` script.

## Run locally
Open `index.html` in a browser, or run a simple local server:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.
