# Publish this portfolio with GitHub Pages

Your free GitHub Pages address will be:

https://prajeshs11.github.io

## 1. Create the repository
1. Sign in to GitHub as `prajeshS11`.
2. Open https://github.com/new
3. Set the repository name to `prajeshs11.github.io` (all lowercase).
4. Set visibility to **Public**. GitHub Free requires a public repository for Pages.
5. Create the repository.

## 2. Upload the website files
1. Extract this ZIP on your computer.
2. Open the `prajesh-cybersecurity-portfolio` folder.
3. In the new GitHub repository, choose **Add file → Upload files**.
4. Upload the contents of that folder (not the enclosing folder): `index.html`, `styles.css`, `script.js`, `prajesh-portrait.jpg`, and `README.md`.
5. Commit the files to the `main` branch.

## 3. Turn on GitHub Pages
1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`, then click **Save**.
4. Wait for the Pages deployment to finish. The site should appear at https://prajeshs11.github.io.

## Important
- GitHub Pages websites are publicly accessible. Only publish details and contact information you are comfortable making public; ask a parent/guardian to review before publishing.
- Do not add passwords, API keys, private documents, or other secrets to the repository.
- This package intentionally has no custom-domain `CNAME` file because you chose the free `github.io` address.
